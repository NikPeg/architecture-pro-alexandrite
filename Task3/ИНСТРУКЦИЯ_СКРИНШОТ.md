# Инструкция: Что скриншотить и куда положить

## Шаги для получения скриншота

### 1. Запуск всего окружения

Выполните команды (или используйте скрипт `setup.sh`):

```bash
cd Task3/architecture-alexandrite-k8s-trace

# Запуск Minikube
minikube start --addons=ingress

# Установка cert-manager
kubectl apply -f https://github.com/cert-manager/cert-manager/releases/download/v1.13.3/cert-manager.yaml

# Развертывание Jaeger
kubectl create namespace observability
kubectl create -f https://github.com/jaegertracing/jaeger-operator/releases/download/v1.51.0/jaeger-operator.yaml -n observability
kubectl wait --for=condition=ready pod -l name=jaeger-operator -n observability --timeout=120s
kubectl apply -f k8s/jaeger-instance.yaml
kubectl wait --for=condition=ready pod -l app.kubernetes.io/name=jaeger -n observability --timeout=120s

# Сборка и развертывание сервисов
minikube image build -t service-a:latest services/service-a/
minikube image build -t service-b:latest services/service-b/
kubectl apply -f k8s/services.yaml
kubectl wait --for=condition=ready pod -l app=service-a --timeout=120s
kubectl wait --for=condition=ready pod -l app=service-b --timeout=120s
```

### 2. Открытие Jaeger UI

В отдельном терминале выполните:

```bash
kubectl port-forward svc/simplest-query 16686:16686
```

Откройте в браузере: **http://localhost:16686**

### 3. Выполнение тестового запроса

В другом терминале выполните:

```bash
kubectl exec -it $(kubectl get pods -l app=service-a -o jsonpath='{.items[0].metadata.name}') -- curl http://service-a:8080
```

Или если curl недоступен:

```bash
kubectl exec -it $(kubectl get pods -l app=service-a -o jsonpath='{.items[0].metadata.name}') -- wget -qO- http://service-a:8080
```

### 4. Поиск трейса в Jaeger UI

1. В Jaeger UI (http://localhost:16686) в левой панели:
   - Выберите сервис **"service-a"** из выпадающего списка "Service"
   - Нажмите кнопку **"Find Traces"**

2. Вы должны увидеть список трейсов (обычно 1-2 трейса)

3. **Кликните на трейс**, чтобы открыть детали

## 📸 Что нужно заскриншотить

Сделайте **ДВА скриншота**:

### Скриншот 1: Список трейсов
- Показывает страницу Jaeger UI с выбранным сервисом "service-a"
- Видны найденные трейсы в списке
- Видно время выполнения, количество spans

### Скриншот 2: Детали трейса (важнее!)
- Показывает **детальный вид трейса** после клика на него
- Видно **дерево вызовов (timeline)**:
  - `service-a-handler` (родительский span)
  - Внутри него `service-b-handler` (дочерний span)
- Видны **временные метки** и **длительность** каждого span
- Видны **атрибуты** spans (tags)

**Идеальный скриншот должен показывать:**
- Временную шкалу (timeline) с двумя spans
- Связь между service-a и service-b
- Время выполнения каждого span

## 📁 Куда положить скриншот

Сохраните скриншоты в папку:

```
Task3/
```

Назовите файлы:
- `jaeger-traces-list.png` (или `.jpg`) - список трейсов
- `jaeger-trace-details.png` (или `.jpg`) - детали трейса

Или можно назвать:
- `screenshot-1.png` и `screenshot-2.png`

## ✅ Проверка скриншота

Убедитесь, что на скриншоте видно:
- ✅ Название сервиса "service-a" в интерфейсе Jaeger
- ✅ Дерево вызовов с service-a → service-b
- ✅ Временная шкала (timeline)
- ✅ Длительность выполнения (duration) каждого span
- ✅ Атрибуты (tags) spans

Если что-то не работает, проверьте логи:
```bash
kubectl logs -l app=service-a --tail=50
kubectl logs -l app=service-b --tail=50
```
